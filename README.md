# PRDsAgent

需求文档 Agent。

## 新成员先读（强制）
在开始任何开发任务前，必须先完成：
1. [项目入门指南](./docs/项目入门指南.md)
2. [项目愿景](./docs/项目愿景.md)
3. [Agent 核心规则](./docs/Agent核心规则.md)
4. [团队协作流程](./docs/团队协作流程.md)

未完成上述步骤，不得领取开发任务或提交 PR。
