# PRDsAgent 项目入门指南

## 第一步：必读文档（约 13 分钟）
1. [项目愿景](./项目愿景.md)（5 分钟）
2. [Agent 核心规则](./Agent核心规则.md)（3 分钟）
3. [团队协作流程](./团队协作流程.md)（5 分钟）

## 第二步：工具准备
- [Notion 日报数据库](https://www.notion.so/31a96011ac3e8066a73dd65ec5318cde?v=31a96011ac3e804cb25e000cfe8e1b49&source=copy_link)（熟悉界面与字段）
- Git 仓库访问权限（确认可拉取、可提交、可发起 PR）

## 第三步：参加启动会议
- 时间：2026-03-23 09:00（Asia/Shanghai）
- 参与人：全体 6 个角色
- 议程：任务分配、流程确认、日报演示、风险识别

## 第四步：开始任务（前置条件）
仅当你完成以下事项后，才能开始实际开发：
- 已完成必读文档学习
- 已完成工具准备
- 已参加启动会议并完成确认

确认口令：
```text
已阅读并理解
```

未完成以上步骤的成员，不进入任务分配与代码评审流程。
