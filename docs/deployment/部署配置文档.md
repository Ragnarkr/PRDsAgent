# PRDsAgent 部署配置文档

## 1. 环境要求
- **Python版本**: 3.8+
- **内存**: ≥2GB
- **磁盘空间**: ≥500MB
- **网络**: 可访问外部依赖（如python-docx）

## 2. 依赖安装
```bash
# 安装Python依赖
pip install -r requirements.txt
pip install -r requirements-dev.txt

# 安装系统依赖（DOCX支持）
# Ubuntu/Debian
sudo apt-get install libxml2-dev libxslt-dev

# CentOS/RHEL  
sudo yum install libxml2-devel libxslt-devel
```

## 3. 服务配置
### 3.1 端口配置
- **默认端口**: 8080
- **可配置环境变量**: `PORT=8080`

### 3.2 文件上传限制
- **最大文件大小**: 10MB
- **可配置环境变量**: `MAX_FILE_SIZE=10485760`

### 3.3 并发配置
- **工作进程数**: CPU核心数
- **可配置环境变量**: `WORKERS=4`

## 4. 启动命令
```bash
# 开发模式
uvicorn src.prds_agent.api:app --host 0.0.0.0 --port 8080 --reload

# 生产模式
gunicorn -k uvicorn.workers.UvicornWorker src.prds_agent.api:app --bind 0.0.0.0:8080 --workers 4
```

## 5. 监控指标
### 5.1 健康检查
- **端点**: `GET /health`
- **检查项**: 服务状态、版本信息、时间戳

### 5.2 性能监控
- **请求计数**: 每分钟请求数
- **响应时间**: P95/P99响应时间
- **错误率**: HTTP 5xx错误率

### 5.3 资源监控
- **CPU使用率**: <80%
- **内存使用率**: <80%
- **磁盘空间**: >100MB可用

## 6. 日志配置
### 6.1 日志级别
- **开发环境**: DEBUG
- **生产环境**: INFO

### 6.2 日志格式
```json
{
  "timestamp": "2026-03-05T23:54:00Z",
  "level": "INFO",
  "message": "Request processed",
  "request_id": "uuid",
  "file_type": "md",
  "response_time": 1.234
}
```

### 6.3 日志轮转
- **保留天数**: 7天
- **单文件大小**: 100MB

## 7. 安全配置
### 7.1 认证（后续版本）
- **API Key**: 通过Header `X-API-Key` 传递
- **密钥管理**: 环境变量 `API_KEY`

### 7.2 限流（后续版本）
- **速率限制**: 100请求/分钟/IP
- **配置**: 环境变量 `RATE_LIMIT=100`

## 8. 备份与恢复
### 8.1 配置备份
- **配置文件**: `config/` 目录
- **备份频率**: 每次部署前

### 8.2 数据备份
- **上传文件**: 临时存储，不持久化
- **分析结果**: 内存中处理，不存储

## 9. 故障排除
### 9.1 常见问题
- **DOCX解析失败**: 确认系统依赖已安装
- **内存不足**: 增加内存或减少并发数
- **端口冲突**: 修改PORT环境变量

### 9.2 调试命令
```bash
# 测试API连通性
curl -X GET http://localhost:8080/health

# 测试文件上传
curl -X POST -F "file=@test.md" http://localhost:8080/analyze
```
