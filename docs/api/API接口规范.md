# PRDsAgent API 接口规范 v0.1

## 1. 概述
本文档定义了PRDsAgent需求文档分析服务的API接口规范，基于Week2任务要求和六角色会议评审结果。

## 2. 基础信息
- **API版本**: v0.1
- **基础URL**: `http://localhost:8080`
- **认证方式**: 无（开发阶段），后续增加API Key认证
- **限流策略**: 100请求/分钟/IP（开发阶段暂不启用）

## 3. 接口列表

### 3.1 分析需求文档
- **端点**: `POST /analyze`
- **描述**: 上传需求文档文件并返回质量分析报告
- **请求格式**: multipart/form-data

#### 请求参数
| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| file | file | 是 | 需求文档文件（支持.md, .txt, .docx） |

#### 成功响应 (200)
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "source_path": "uploaded_file.md",
    "issues": [
      {
        "rule_id": "CM001",
        "category": "completeness_check", 
        "severity": "warning",
        "message": "需求完整性缺失：目标, 范围",
        "suggestion": "补充目标、范围、依赖、验收标准等关键要素。",
        "evidence": "用户登录功能...",
        "line_no": 5
      }
    ]
  }
}
```

#### 错误响应
| 状态码 | 错误码 | 描述 |
|--------|--------|------|
| 400 | INVALID_FILE_TYPE | 不支持的文件类型 |
| 400 | FILE_TOO_LARGE | 文件过大（>10MB） |
| 422 | PARSE_ERROR | 文档解析失败 |
| 500 | INTERNAL_ERROR | 服务器内部错误 |

### 3.2 健康检查
- **端点**: `GET /health`
- **描述**: 服务健康状态检查
- **响应**:
```json
{
  "status": "healthy",
  "version": "0.1.0",
  "timestamp": "2026-03-05T23:54:00Z"
}
```

## 4. 错误码规范
| 错误码 | HTTP状态 | 描述 |
|--------|----------|------|
| 1000 | 400 | 无效的请求参数 |
| 1001 | 400 | 不支持的文件类型 |
| 1002 | 400 | 文件大小超出限制 |
| 2000 | 422 | 文档内容解析失败 |
| 5000 | 500 | 服务器内部错误 |

## 5. 性能指标
- **P95响应时间**: ≤6秒
- **P99响应时间**: ≤8秒  
- **成功率**: ≥99%
- **并发能力**: 支持20并发用户

## 6. 安全要求
- **输入验证**: 所有文件类型和大小验证
- **沙箱执行**: 文档解析在隔离环境中进行
- **认证授权**: 后续版本增加API Key认证
- **限流保护**: 防止恶意请求

## 7. 版本管理
- **当前版本**: v0.1（开发阶段）
- **兼容性**: 向后兼容，字段只增不减
- **废弃策略**: 字段废弃前至少保留2个版本

## 8. 附录

### 8.1 支持的文件格式
- Markdown (.md, .markdown)
- 纯文本 (.txt)  
- Word文档 (.docx)

### 8.2 规则引擎检测项
- CM001: 完整性检查
- AC001/AC002: 验收标准检测  
- CF001: 数值冲突检测
- FT001: 模糊词汇检测
