# 性能与运维基线协议（DevOps）

## 1) 压测与性能基线协议

### 固定压测配置
- 请求总量：500（另加预热 50，不计入统计）
- 并发：20
- 压测时长：10 分钟
- 轮次：3 轮
- 环境：`staging` 固定规格节点（需记录 CPU/内存/实例数）

### 请求与统计口径
- 使用固定请求画像版本 + 随机种子（确保可复现）。
- 指标：
  - P95 时延
  - 成功率
  - 5xx 率
  - 超时率
- Gate 判定采用“最差值”：
  - P95 取 3 轮最大值
  - 成功率取 3 轮最小值
  - 5xx/超时率取 3 轮最大值

### Gate-M1 通过阈值
- P95 <= 6s
- 成功率 >= 99%
- 5xx 率 <= 0.5%
- 超时率 <= 0.5%

## 2) 告警验收量化标准

- P1 告警：5 分钟内送达率 >= 99%
- P2 告警：10 分钟内送达率 >= 99%
- 统计窗口：24 小时
- 最小样本：>=20 条告警事件
- 验收方式：演练注入 + 实际链路回执双重校验

## 3) 合规前置闸门（执行顺序必须前置）

### 数据授权
- 未授权数据不得进入评测集。
- 每批次保留授权记录（来源、授权人、时间戳）。

### 数据脱敏
- 敏感字段脱敏覆盖率必须达到 100%。
- 抽检不通过则阻断后续评测流程。

### RBAC
- 最小权限原则：按角色分配读取/导出/操作权限。
- 非授权账号访问必须被拒绝并记录审计事件。

### 审计
- 记录上传、解析、导出、权限变更日志。
- 日志需可追溯至任务ID/操作者/时间。
