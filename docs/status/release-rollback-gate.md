# 发布/回滚准入矩阵（DevOps）

## 1) 发布准入（staging -> Gate）

| 类别 | 准入条件 | 证据产出 |
|---|---|---|
| 质量 | P0=0，P1 有已批准处理计划 | 缺陷清单 + 分级说明 |
| 性能 | P95/成功率/5xx/超时均满足 Gate 阈值 | 三轮复测报告 |
| 运维 | 告警链路验收通过（P1/P2 送达率达标） | 告警演练报告 |
| 合规 | 数据授权、脱敏、RBAC、审计检查通过 | 合规检查清单 |

## 2) 回滚触发阈值

任一触发即执行回滚预案：
- 发布后 15 分钟内 P95 > 6.5s 且持续 5 分钟
- 成功率 < 98.5%
- 5xx 率 > 1.0%
- 关键链路告警丢失或延迟超 SLA
- 出现 P0 级安全/数据完整性问题

## 3) RTO / RPO 目标

- RTO：<= 30 分钟（触发到恢复可用）
- RPO：<= 15 分钟（可接受数据回退窗口）

## 4) 回滚后健康检查项

- [ ] 核心 API 健康检查全部通过（2xx 成功）
- [ ] 关键业务链路端到端回归通过
- [ ] 监控数据恢复正常采集
- [ ] 告警链路恢复可达
- [ ] 审计日志持续写入正常
