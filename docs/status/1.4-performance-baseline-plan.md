- 三轮压测，每轮统一口径: `500请求(预热50) + 20并发 + 10分钟`
- 统计指标:
  - `P95 <= 6s`
  - `成功率 >= 99%`
  - `5xx率 <= 0.5%`
  - `超时率 <= 0.5%`

  - 固定请求画像版本、随机种子、工具版本、节点规格
  - 三轮最差值作为 Gate 判定
