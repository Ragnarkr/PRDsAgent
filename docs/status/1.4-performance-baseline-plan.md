## 指标定义
### 核心指标
- **P95时延**: <= 6s (Gate-M1阈值)
- **成功率**: >= 99% (Gate-M1阈值)
- **5xx率**: <= 0.5% (Gate-M1阈值)
- **超时率**: <= 0.5% (Gate-M1阈值)

### 统计口径
- **重试模式**: latest_attempt（只计算最后一次尝试）
- **4xx处理**: 默认不计入成功，但提供--count-4xx-as-success选项
- **Gate判定**: 采用"最差值"原则
  - P95取3轮最大值
  - 成功率取3轮最小值  
  - 5xx/超时率取3轮最大值
