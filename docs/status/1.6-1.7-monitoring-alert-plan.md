## 监控指标配置
### 1. API 层监控
- [ ] **请求量监控**: QPS、总请求数
- [ ] **时延监控**: P95/P99 响应时间
- [ ] **错误率监控**: 5xx 错误率、超时率
- [ ] **成功率监控**: 整体成功率 >= 99%

### 2. 任务层监控
- [ ] **队列深度监控**: 异步任务队列长度
- [ ] **任务等待时长**: 任务从提交到开始处理的时间
- [ ] **任务成功率**: 异步任务成功完成率
- [ ] **任务处理时长**: 任务从开始到完成的处理时间

### 3. 模块层监控
- [ ] **解析成功率**: 文档解析成功/失败率
- [ ] **规则引擎耗时**: 规则检查处理时间
- [ ] **LLM 耗时/失败率**: LLM 调用延迟和失败率
- [ ] **报告生成耗时**: 报告生成处理时间

### 4. 资源层监控
- [ ] **CPU 使用率**: 容器/进程 CPU 使用率
- [ ] **内存使用率**: 容器/进程内存使用率
- [ ] **磁盘使用率**: 磁盘空间使用情况
- [ ] **容器重启次数**: 异常重启监控

## 告警配置
### P1 告警（5分钟内响应）
- [ ] **API 可用性低于阈值**: 成功率 < 99%
- [ ] **5xx 持续高位**: 5xx 率 > 0.5% 持续 5 分钟
- [ ] **队列持续积压**: 队列深度 > 300 持续 10 分钟
- [ ] **LLM 不可用且降级失效**: LLM 服务不可用且规则兜底失败

### P2 告警（30分钟内处理）
- [ ] **P95 时延持续超阈值**: P95 > 6s 持续 10 分钟
- [ ] **异步任务时长持续超阈值**: 任务处理时间 > 60s 持续 10 分钟
- [ ] **解析失败率异常升高**: 解析失败率 > 1% 持续 10 分钟

### P3 告警（工作时段处理）
- [ ] **资源水位过高**: CPU > 80% 或内存 > 80% 持续 30 分钟
- [ ] **日志采集延迟**: 日志收集延迟 > 5 分钟

## 告警验收量化标准
### 送达率要求
- [ ] **P1 告警**: 5 分钟内送达率 >= 99%
- [ ] **P2 告警**: 10 分钟内送达率 >= 99%
- [ ] **统计窗口**: 24 小时
- [ ] **最小样本**: >= 20 条告警事件
- [ ] **验收方式**: 演练注入 + 实际链路回执双重校验

## 合规前置闸门
### 数据安全
- [ ] **数据授权**: 未授权数据不得进入评测集
- [ ] **数据脱敏**: 敏感字段脱敏覆盖率必须达到 100%
- [ ] **RBAC**: 最小权限原则，按角色分配权限
- [ ] **审计日志**: 记录上传、解析、导出、权限变更日志
